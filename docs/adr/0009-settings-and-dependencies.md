# Настройки читаются один раз, зависимости передаются явно

Бот читает переменные окружения только в `settings.py` (`Settings.from_env()`). `main()` собирает
из настроек зависимости — соединение с Redis и `StrapiClient` — и кладёт их в
`application.bot_data`. Остальные модули получают клиентов аргументами: по сигнатуре функции
видно, что ей нужно для работы.

## Контекст

До этого решения окружение читали три функции:

- `main()` — `TELEGRAM_TOKEN`;
- `fsm.get_database_connection()` — `REDIS_HOST`, `REDIS_PORT`, `REDIS_PASSWORD`;
- `strapi.client_from_env()` — `STRAPI_URL`, `STRAPI_API_TOKEN`.

`client_from_env()` вызывалась ещё и глубоко внутри хэндлеров и экранов. Объявление функции
говорило только о её аргументах, а на деле ей требовался токен из окружения: чтобы понять
зависимости, приходилось вычитывать код. Тесты вынужденно подменяли env, а не передавали
зависимости.

## Рассмотренные варианты

- **Оставить чтение env на местах** — меньше правок, но скрытые зависимости и хрупкие тесты
  остаются.
- **Глобальные переменные и `configure()`** — env всё равно читается вне `main()`, а порядок
  инициализации становится неявным требованием.
- **`Settings.from_env()` в `main()` и явная передача** — выбрано: одна точка чтения env,
  зависимости видны в сигнатурах, тесты собирают их вручную.
- **Передавать весь `Settings` в каждую функцию** — лишний шум: функции нужен клиент или
  соединение, а не весь конфиг.

## Последствия

- `os.getenv` / `os.environ` встречаются только в `settings.py`; это проверяется одним `grep`.
- `create_database_connection(host, port, password)` и `StrapiClient(base_url, token)` не знают
  про окружение.
- Хэндлеры достают клиента из `context.bot_data`, экраны и вспомогательные функции получают его
  аргументом.
- Пустой `STRAPI_API_TOKEN` теперь останавливает запуск с понятной ошибкой; раньше бот стартовал
  и показывал «Каталог недоступен» только на `/start`.
- Smoke-тест кладёт `FakeRedis` и клиента в `bot_data` — подменять env не нужно.
- Конфиги Strapi (`cms/config/*.js`) продолжают читать env через `env()`: это штатный слой
  конфигурации фреймворка, а не код бота.
